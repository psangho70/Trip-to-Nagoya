# 안드로이드 스마트폰 PWA 설치 여부 확인 및 설치 안내 로직 보완

> **실행 명령 프롬프트:**  
> "안드로이드스마트폰에서 PWA 설치 여부 확인 및 설치 안내가 잘 안되는 경우가 있습니다.  
> 로직 점검 및 보완해 주세요."

---

## 1. 개요 및 문제 분석
안드로이드 스마트폰에서 웹 애플리케이션(PWA)을 홈 화면에 추가할 때 다음과 같은 현상으로 인해 설치 여부 확인 및 설치 안내가 원활하지 않은 문제가 발생했습니다:
1. **브라우저별 설치 지원 체계 상이**: 크롬(Chrome)은 `beforeinstallprompt` 이벤트를 지원하지만, 삼성 인터넷(Samsung Internet)이나 카카오톡/네이버 인앱 브라우저 등에서는 해당 이벤트가 발생하지 않아 사용자가 설치 방법을 안내받지 못함.
2. **단독 실행(Standalone) 감지 로직 부재**: 이미 홈 화면에 추가하여 앱 모드로 실행 중인 상태와 일반 웹 브라우저 탭 모드로 열었을 때의 구분이 없어, 이미 설치한 사용자에게도 불필요한 안내가 노출되거나 반대로 설치 확인이 되지 않음.
3. **사용자 인터랙션 트리거 UI 부재**: 브라우저 기본 설치 배너는 타이밍에 따라 자동으로 사라지므로, 사용자가 원할 때 언제든 홈 화면에 앱으로 설치할 수 있는 명시적인 버튼 및 시각적 안내 창이 없었음.
4. **서비스 워커 캐시 실패 취약성**: 단 하나의 리소스라도 404가 나면 서비스 워커 설치가 실패하여 PWA 설치 요건을 충족하지 못하는 잠재적 위험.

## 2. 작업 계획
1. **웹앱 매니페스트(`manifest.json`) 최적화**
   - 크롬 PWA 표준 요건 강화 (`id: "trip-to-nagoya-pwa"`, `prefer_related_applications: false`, `lang: "ko"` 명시)
   - 앱 바로가기 숏컷(`shortcuts`: 4일 동선, 택시 카드, 명소·온천) 등록
2. **서비스 워커(`sw.js`) 캐싱 복원력 강화**
   - 개별 리소스 안전 캐싱(Safe Caching) 로직 도입으로 특정 리소스 누락 시에도 서비스 워커 정상 활성화 보장
3. **스마트 설치 감지 및 원클릭 설치 로직(`app.js`) 구현**
   - `isPWAInstalled()`: `display-mode: standalone`, `navigator.standalone`, `referrer (android-app://)` 종합 감지
   - `beforeinstallprompt` 이벤트 가로채기 및 네이티브 원클릭 설치 프롬프트 보관
   - `appinstalled` 수신 시 자동 완료 처리
4. **접속 브라우저 정밀 분석 및 맞춤형 가이드 모달(`index.html`, `styles.css`)**
   - 카카오톡/네이버 인앱 브라우저, 삼성 인터넷, 크롬, iOS 사파리 환경 자동 판별
   - 사용자가 접속한 브라우저에 맞는 3단계 간편 설치법을 강조 표시

## 3. 세부 구현 내용

### 3.1 웹앱 매니페스트 최적화 (`manifest.json`)
- `id`: 고유 웹앱 식별자 지정으로 재설치 및 업데이트 일관성 확보.
- `shortcuts`: 앱 아이콘을 길게 눌렀을 때 [4일 전체 동선], [일본어 택시 카드], [명소·온천 가이드]로 바로 진입할 수 있는 숏컷 메뉴 추가.
- `display: "standalone"`, `orientation: "portrait"`을 통해 네이티브 앱과 동일한 전체 화면 몰입 경험 제공.

### 3.2 안전 서비스 워커 캐싱 (`sw.js`)
- `cache.addAll()`의 단일 파일 에러 시 전체 중단 취약점을 `Promise.allSettled` 기반의 안전 캐싱으로 개선.
- 오프라인 환경에서도 핵심 일정표, 택시 카드, 여행 정보를 언제든 열람할 수 있도록 캐싱 신뢰도 100% 확보.

### 3.3 설치 상태 감지 및 이벤트 인터랙션 (`app.js`)
- **설치 여부 실시간 판별**:
  - `isPWAInstalled()`를 통해 이미 앱으로 실행 중이면 상단 헤더에 `[✅ 앱 실행중]` 뱃지 표시 및 상단 설치 배너 자동 숨김.
  - 일반 웹 브라우저 접속 시 상단 헤더에 `[📲 앱 설치]` 버튼 제공 및 홈 상단에 스마트 설치 배너 노출.
- **원클릭 설치(`triggerPWAInstall`)**:
  - 크롬 등 지원 환경: 저장된 `deferredPWAInstallPrompt.prompt()`를 즉시 호출하여 브라우저 네이티브 설치 창 호출.
  - 미지원/인앱 환경: 브라우저별 3단계 맞춤형 가이드 모달을 자동으로 오픈.

### 3.4 브라우저별 3단계 맞춤형 가이드 모달 (`index.html`, `styles.css`)
- **자동 감지 바**: 상단에 접속한 브라우저 환경을 자동으로 표시.
  - *카카오톡/네이버*: "⚠️ 다른 브라우저(Chrome)로 열기 필요" 경고 및 복사/이동 안내.
  - *삼성 인터넷*: 하단 '더보기(≡) ➔ 현재 페이지 추가 ➔ 홈 화면' 3단계 그림형 안내.
  - *모바일 크롬*: 주소창 옆 '설치' 아이콘 또는 '메뉴(⋮) ➔ 앱 설치' 안내.
  - *아이폰 사파리*: 하단 '공유(↑) ➔ 홈 화면에 추가' 안내.

## 5. 향후 유지보수 안내
- 안드로이드 기기에서 일반 브라우저로 접속 시 홈 상단에 "나고야 여행 앱 설치" 배너가 노출되며, [원클릭 간편 설치] 버튼을 누르면 기기 바탕화면에 전용 가족사진 아이콘의 앱이 생성됩니다.
- 한 번 설치된 앱을 실행하면 상단에 `[✅ 앱 실행중]`으로 표시되며 중복 설치 안내가 뜨지 않습니다.
