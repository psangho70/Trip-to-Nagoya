# 이미지 중복 현상 및 크게 보기 오류 원인 분석 및 해결 보고서

## 1. 실행 명령 프롬프트
> **사용자 요청 사항**:  
> "첨부 이미지를 확인하세요.  
> 한 장소에 동일하게 보이는 2장의 이미지가 있는 경우가 있고, '터치하여 크게 보기' 기능이 작동하지 않는 이미지가 있습니다. 확인하고 수정해 주세요."

---

## 2. 현상 분석 및 원인 규명
사용자가 제공한 첨부 화면 2장을 정밀 분석한 결과:
1. **한 장소에 동일한 이미지가 2장 나타난 원인**:
   - `nagoya-castle`(나고야성)의 3번째 이미지 URL(`Kinshachi-Yokocho_Yoshinao-Zone_201804.jpg`)이 404 에러로 로드에 실패함.
   - 썸네일 태그의 `onerror` 핸들러가 작동하여 1번째 이미지인 `Nagoya_Castle(Edit2).jpg`로 자동 대체되면서, 화면상에 1번째와 3번째가 완전히 동일한 천수각 사진으로 2장이 노출되었음.
   - 또한 2번째 이미지(`Nagoya_Castle_Honmaru_Palace.jpg`)가 전쟁 전 흑백 사진이어서 화려하게 복원된 금박 궁전 느낌이 전달되지 못함.
2. **"터치하여 크게 보기"가 작동하지 않고 깨진 이미지 아이콘이 뜬 원인**:
   - 썸네일 클릭 시 `openImageModal(img.url, ...)`로 원래 404 실패 URL을 모달 이미지에 그대로 전달함.
   - 모달의 `modal-img`에는 `onerror` 방어 처리가 없어 404 에러로 인해 깨진 이미지 아이콘(엑스박스)이 팝업에 노출됨.
3. **타 장소 간 이미지 중복 및 잠재 오류**:
   - 온천 노천탕 사진(`Hirayu_Onsen_Rotenburo.jpg`)이 캐널 리조트와 유키치로에 중복 사용됨.
   - 아츠타 신궁과 호라이켄 간에 장어덮밥 사진(`Hitsumabushi1.jpg`)이 중복 사용됨.
   - 타카시마야와 빅카메라 간에 역 출구 사진이 중복 사용됨.
   - 위키미디어 직접 해시 경로 대신 위키미디어 영구 리디렉션 API인 `Special:FilePath` 형식을 적용하여 404 오류를 원천 차단해야 함.

## 3. 조치 내용 및 상세 변경 내역

### 1) 16개 전체 장소 이미지 URL 전면 검증 및 교체 (`Special:FilePath`)
- 위키미디어 커먼즈의 해시 경로 대신 영구 보존 공식 리다이렉트 엔드포인트인 `https://commons.wikimedia.org/wiki/Special:FilePath/<파일명>`으로 전면 교체.
- Node.js 자동화 스크립트를 통해 전체 16개 장소 34개 이미지의 HTTP 302/200 정상 응답을 100% 전수 검증 완료.

### 2) 나고야성 실제 컬러 현장 사진 3종 고유 분리 (중복 해결)
- **1번 (천수각)**: `Nagoya_Castle(Edit2).jpg` (나고야성의 웅장한 실제 천수각과 황금 샤치호코)
- **2번 (혼마루 어전)**: `Inside_view_of_Hommaru_Palace_of_Nagoya_Castle_2.JPG` (복원된 혼마루 어전 내부 실제 황금빛 금박 벽화 컬러 사진)
- **3번 (긴샤치요코초)**: `Kinshachi_Yokocho.jpg` (나고야성 정문 앞 전통 미식 거리 긴샤치요코초 실제 풍경)

### 3) 타 장소 간 사진 중복 완전 제거
- **아츠타 신궁**: 역사적인 오다 노부나가의 봉납 유적인 '노부나가 담장(`Nobunagabei_in_Atsuta_Jingu_Shrine_2014.jpg`)' 및 '신궁 본전 배전' 배치 (호라이켄 장어덮밥 중복 제거)
- **JR 타카시마야**: 백화점 지하 데파치카 No.1 명물 '반카쿠 유카리 새우 센베이(`Bankaku_Yukari.jpg`)' 배치 (빅카메라 외관 중복 제거)
- **유아미노시마 온천**: 나가시마 온천 최고급 료칸 '호텔 하나미즈키(`Hotel_hanamizuki.jpg`)' 배치 (재즈드림 아울렛 리조트 전경 중복 제거)
- **캐널 리조트**: 이국적인 야외 자연 노천탕(`Japanese_bath_dsc05407.jpg`) 배치 (유키치로 히노키탕 중복 제거)

### 4) '터치하여 크게 보기' 모달 클릭 로직 및 방어 코드 강화
- `gallery-item` 클릭 시 `this.querySelector('img').src || '${img.url}'`를 모달에 넘기도록 수정하여, 화면에 정상 렌더링된 이미지를 모달에서도 100% 동일하게 확대 표시.
- `openImageModal` 함수 내부의 `modalImg`에 `onerror` 핸들러 및 `this.onerror = null;` 방어 로직을 추가하여 모달에서 엑스박스가 뜨는 현상을 원천 방지.
