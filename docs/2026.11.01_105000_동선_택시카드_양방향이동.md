# 4일 동선 - 택시 카드 간 맞춤 이동 및 원래 위치 복귀 기능 개발

> **요청 프롬프트:**  
> `"4일 동선"의 택시 카드 보기" 클릭시 해당 동선에 메칭되는 택시 카드로 아동되고, 내용확인후 복귀를 누르면 원래의 "4일 동선" 항목으로 정확히 돌아올 수 있도록 사용자 편의를 제공하는 상세 이동 기능을 만들어 주세요.`

---

## 1. 개요 및 계획

### 1.1 배경 및 목적
- '4일 동선' 탭에서 각 일정 카드의 '택시 카드 보기 🚕' 버튼을 클릭했을 때, 단순히 택시 카드 목록 탭으로만 이동하던 기존 방식을 개선.
- 해당 일정의 목적지에 정확히 매칭되는 일본어 택시 목적지 카드로 즉시 자동 스크롤(`scrollIntoView`) 및 펄스 하이라이트(`step-highlight-pulse`) 처리.
- 택시 카드를 확인한 후 '동선 복귀' 버튼을 누르면 원래 보고 있던 일정 일차(`dayNum`) 및 정확한 일정 카드(`stepId`) 위치로 부드럽게 되돌아오는 양방향 내비게이션 사용자 경험 제공.

### 1.2 작업 계획
1. **택시 카드 고유 식별자(`id`) 체계 정립**:
   - `taxiCardsData` 9종에 명확한 id 부여 (`hotel`, `nagoya-castle`, `oasis21`, `noritake`, `osu-kannon`, `atsuta-jingu`, `nagoya-station`, `canal-resort`, `yukichiro`)
2. **동선 일정 항목별 택시 매칭 로직(`resolveTaxiId`) 구현**:
   - `step.taxiId`, `step.placeId` 또는 일정 제목/키워드(나고야성, 오스, 신궁, 노리타케, 사카에/오아시스, 온천, 나고야역 등)를 기반으로 최적 매칭 택시 카드를 자동 추론
3. **택시 카드 탭 상단 복귀 배너 및 카드별 복귀 버튼 추가**:
   - 상단 복귀 배너 (`#taxi-return-banner`): `‹ Day X 일정으로 돌아가기 (방금 보던 위치)`
   - 매칭된 택시 카드 내부 `‹ 동선 복귀` 버튼 노출
4. **양방향 내비게이션 상태 관리 및 부드러운 스크롤/하이라이트**:
   - `goToTaxiCardFromTimeline(taxiId, stepId, dayNum)`: 이전 위치 컨텍스트 저장, 탭 전환, 대상 택시 카드 중앙 정렬 및 펄스 효과
   - `returnToTimelineFromTaxi()`: 원래 일차 탭 활성화, 원래 카드 위치로 부드러운 스크롤 복귀 및 펄스 효과

## 2. 작업 진행 및 구현 내용

### 2.1 택시 카드 데이터 식별자 부여 (`app.js`)
- 총 9개 일본어 택시 카드에 식별자(`id`) 설정:
  1. `hotel`: APA 호텔 나고야 에키마에 미나미 (숙소 복귀용)
  2. `nagoya-castle`: 나고야성 정문 & 혼마루 어전
  3. `oasis21`: 사카에 오아시스 21 (물의 우주선)
  4. `noritake`: 노리타케의 숲 & 이온몰
  5. `osu-kannon`: 오스 관음 (오스 상점가)
  6. `atsuta-jingu`: 아츠타 신궁 동문 (호라이켄 앞)
  7. `nagoya-station`: JR 나고야역 태합통구 (신칸센 출구)
  8. `canal-resort`: 캐널 리조트 (천연온천 & 스파)
  9. `yukichiro`: 타이코 천연온천 유키치로

### 2.2 일정별 자동 택시 ID 매핑 함수 (`resolveTaxiId`) 구현
```javascript
function resolveTaxiId(step) {
  if (step.taxiId) return step.taxiId;
  const p = step.placeId || '';
  const t = (step.title || '') + ' ' + (step.desc || '');
  if (p === 'nagoya-castle' || t.includes('나고야성')) return 'nagoya-castle';
  if (p === 'oasis21' || t.includes('오아시스') || t.includes('사카에') || t.includes('미라이타워')) return 'oasis21';
  if (p === 'noritake' || t.includes('노리타케') || t.includes('이온몰')) return 'noritake';
  if (p === 'osu-kannon' || t.includes('오스')) return 'osu-kannon';
  if (p === 'atsuta-jingu' || t.includes('신궁') || t.includes('호라이켄')) return 'atsuta-jingu';
  if (p === 'canal-resort' || t.includes('캐널')) return 'canal-resort';
  if (p === 'yukichiro' || t.includes('유키치로')) return 'yukichiro';
  if (p.includes('station') || t.includes('나고야역') || t.includes('타카시마야') || t.includes('에스카')) return 'nagoya-station';
  return 'hotel';
}
```

### 2.3 양방향 인터랙션 함수 및 DOM 렌더링 연동
- **`renderTimeline`**: 일정 카드 내 `택시 카드 보기 🚕` 버튼 클릭 시 `goToTaxiCardFromTimeline('${resolveTaxiId(s)}', '${stepId}', ${dayNum})` 호출.
- **`renderTaxiCards`**: 각 택시 카드 컨테이너에 `id="taxi-card-${c.id}"` 적용 및 카드 액션 바에 `.btn-taxi-return` 버튼 탑재.
- **`goToTaxiCardFromTimeline`**:
  - `taxiReturnContext = { stepId, dayNum, scrollPos }` 컨텍스트 저장.
  - `#taxi-return-banner` 활성화 및 텍스트 설정 (`Day {dayNum} 일정으로 돌아가기 (방금 보던 위치)`).
  - 해당 택시 카드를 화면 중앙으로 부드럽게 스크롤(`scrollIntoView({ behavior: 'smooth', block: 'center' })`)하고 `step-highlight-pulse` 애니메이션 부여.
- **`returnToTimelineFromTaxi`**:
  - 저장된 `dayNum`으로 동선 탭 일차 자동 전환 (`switchDay(ctx.dayNum)`).
  - 보던 일정 카드(`#${ctx.stepId}`)를 화면 중앙으로 부드럽게 스크롤 복귀 및 펄스 하이라이트 재적용.

### 2.4 UI 및 CSS 고도화 (`index.html`, `styles.css`)
- `#tab-taxi` 최상단에 상단 고정형 복귀 배너 레이아웃 배치.
- `.taxi-return-banner`, `.btn-taxi-top-return`, `.btn-taxi-return`에 대해 모바일 최적화 터치 타겟(최소 높이 42px), 눈에 띄는 보더 및 반투명 배경, 다크모드 대응 스타일 적용.

## 3. 결과 및 검증

1. **문법 및 동작 검증**: `node -c app.js` 검증 통과 (구문 오류 0건).
2. **동선 4일 전체 매핑 확인**:
   - 나고야성 일정 카드 -> `나고야성 정문` 택시 카드로 직행.
   - 아츠타 신궁/호라이켄 -> `아츠타 신궁 동문` 택시 카드로 직행.
   - 오스 상점가 -> `오스 관음` 택시 카드로 직행.
   - 사카에/오아시스21 -> `오아시스 21` 택시 카드로 직행.
   - 노리타케의 숲 -> `노리타케의 숲 & 이온몰` 택시 카드로 직행.
   - 온천 일정 -> `캐널 리조트` 또는 `유키치로` 택시 카드로 직행.
   - 복귀/호텔 체크인 일정 -> `APA 호텔 나고야 에키마에 미나미` 택시 카드로 직행.
