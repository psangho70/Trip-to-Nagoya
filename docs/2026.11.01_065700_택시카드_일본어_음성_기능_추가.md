## 1. 개발 계획 및 요구사항 분석

### 1.1 사용자 요구사항
- 첨부 이미지에서 확인된 **'기사님께 보여주는 일본어 목적지 카드'**에 일본어 텍스트뿐만 아니라, **택시 기사에게 직접 일본어 음성(TTS)으로 목적지를 들려줄 수 있는 오디오 재생 기능**을 추가.
- 차량 내부 소음과 일본 택시 기사님의 연령대를 고려하여, **또박또박하고 명확한 발음(SpeechSynthesis ja-JP)**으로 전달되어야 함.

### 1.2 기술 구현 방안
1. **Web Speech API (`SpeechSynthesis`) 네이티브 연동**:
   - 외부 라이브러리나 서버 트래픽 없이 스마트폰(iOS Safari, Android Chrome 등)과 PC 브라우저에서 네이티브 일본어 음성(`ja-JP`) 즉시 출력.
   - 발화 속도(`rate: 0.88`)와 음량(`volume: 1.0`)을 최적화하여 차량 주행 중에도 또렷하게 들리도록 설정.
2. **UI/UX 개선**:
   - 택시 목적지 카드마다 눈에 띄는 **`[🔊 기사님께 들려주기]`** 원터치 버튼 배치.
   - 음성 재생 중 실시간 펄스 애니메이션(소리 나는 효과) 및 안내 토스트 표시.
   - 일본어 실제 회화 문장 ("運転手さん、〇〇までお願いします。")을 자연스럽게 조합하여 발화.
3. **타임라인 및 숙소 바우처 연계**:
   - 택시 카드 탭뿐만 아니라 4일 동선 타임라인과 숙소 정보 카드에서도 필요 시 일본어 발음을 바로 들어볼 수 있도록 연동.
