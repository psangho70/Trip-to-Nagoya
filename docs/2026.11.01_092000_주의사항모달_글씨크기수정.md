# 여행 주의사항 팝업 모달 전환 및 글씨 크기 확대 기능 수정

## 실행을 명령받은 프롬프트
> 1. 첨부 이미지의 내용은 상시적으로 보여주지 말고, 처음 실행시 "여행 주의사항"으로 팝업 모달 창으로 보여주세요.
> 2. 글씨 크기 기능이 작동하지 많습니다. 원래 기능 구현 의도를 알려주세요.

---

## 1. 작업 계획
1. **상단 터미널 주의 경고 배너 상시 노출 제거 및 팝업 모달 전환**:
   - 상단 헤더에 고정 노출되던 터미널 경고 바(`terminal-alert-bar`)를 제거하여 화면을 넓고 깔끔하게 개선.
   - 첫 실행 시(웹페이지 접속 시) 출국/귀국 터미널 상이 정보, 나고야성 연말 휴관 안내, 4인 택시 이동 팁이 담긴 **"⚠️ 여행 주의사항" 팝업 모달 창** 자동 노출.
   - "오늘 하루 동안 이 창 열지 않기" 체크박스 지원(LocalStorage 연동).
   - 상단 헤더 및 홈 요약 카드에 `[⚠️ 주의사항]` 버튼을 두어 언제든 다시 열람할 수 있도록 개선.
2. **글씨 크기 기능 오류 원인 분석 및 정상 동작 수정**:
   - **원래 구현 의도**: 부모님을 동반한 성인 4인 가족 여행에서 스마트폰을 통한 야외 이동 시 작은 글씨로 인한 피로를 덜고 가독성을 극대화하기 위해, 원터치로 전체 글씨와 카드를 약 1.2배(18px) 확대하는 **고시인성 모드** 제공.
   - **오류 원인 규명**: 전체 CSS 폰트 크기가 `rem` 단위(루트 `html` 기준)로 되어 있으나, 자바스크립트와 CSS에서 `body.large-font`에만 스타일을 적용하여 부모 요소인 `html`에 CSS 변수가 전달되지 않았던 구조적 원인 해결.
   - **수정 조치**: `html.large-font`에 `font-size: 18px !important;` 및 CSS 변수를 바인딩하고 자바스크립트에서 `documentElement`와 `body`를 함께 토글하도록 수정하여 즉각 1.2배 확대 반영.

## 2. 작업 진행 및 결과
1. **`index.html` 수정**:
   - 헤더 내 상시 배너 제거 및 `[⚠️ 주의사항]` 버튼 추가.
   - 하단에 `notice-modal` (출국/귀국 터미널 비교 박스, 나고야성 연말 휴관 안내, 4인 택시 꿀팁, 오늘 하루 안 보기 체크박스) 추가.
   - 홈 탭 요약 헤더에 `[⚠️ 필수 주의사항 확인]` 버튼 연동.
2. **`styles.css` 수정**:
   - `html.large-font, body.large-font` 전역 확대 규칙 및 `html.large-font { font-size: 18px !important; }` 적용.
   - 주의사항 모달(`notice-modal-content`, `terminal-compare-grid`, `terminal-box` 등) 고대비 디자인 추가.
3. **`app.js` 수정**:
   - `initFontSize()`: `document.documentElement`와 `document.body` 클래스 동시 토글 및 로컬 스토리지 저장.
   - `initNoticeModal()`, `openNoticeModal()`, `closeNoticeModal()`, `confirmNoticeModal()` 구현 (오늘 하루 안 보기 로컬스토리지 연동 및 350ms 후 자동 팝업).
4. **Git 백업**:
   - 변경 사항을 Git 커밋 및 GitHub 원격 저장소(`main`)에 푸시하여 GitHub Pages 자동 배포 반영.
